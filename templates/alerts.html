Aturan Pemicu Insiden Otomatis

Notifikasi akan otomatis dikirimkan ke kanal aktif ketika ambang batas metrik berikut terlewati.

Ambang Batas Beban CPU (CPU Usage)
Memicu alert saat konsumsi prosesor host melampaui persentase yang ditentukan.

Ambang Batas Penggunaan Memori (RAM Usage)
Memicu alert saat kapasitas RAM host terserap melebihi batas toleransi.
%
Ambang Batas Partisi Root Storage (Disk Usage)
Memicu peringatan jika ruang penyimpanan utama host hampir habis.
%
Deteksi Anomali S.M.A.R.T. Drive Fisik
Memicu alert darurat jika ada drive yang mengalami pending sectors, bad sector, atau penurunan wear level kritis.
Pemberitahuan Reboot Kernel / OS Diperlukan
Mengirimkan notifikasi jika pembaruan APT mendeteksi kebutuhan restart sistem (`/var/run/reboot-required`).
