Panduan Cepat Menambahkan Remote Cloud
Untuk menambahkan remote baru seperti Google Drive atau S3:
  1. Buka terminal server host atau jalankan di web terminal: rclone config
  2. Pilih n (New remote), masukkan nama (misal: gdrive atau s3_backup).
  3. Pilih tipe penyimpanan yang diinginkan dan ikuti langkah otorisasi.
  4. Setelah remote tersimpan di host, refresh halaman ini untuk langsung mengaktifkannya!

Penjadwalan Backup Otomatis

Atur jadwal berkala pembuatan snapshot sistem agar server terlindungi secara otomatis tanpa intervensi manual.

Disarankan memilih jam dini hari (misal 02:00 WIB) saat beban trafik server minim.
