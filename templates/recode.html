Tulis tugas lalu tekan Jalankan untuk sekali eksekusi, atau buka REPL untuk sesi percakapan penuh. Agent berjalan di mesin target yang dikonfigurasi lewat tombol gear.

Konfigurasi Recode Agent

Nama atau path absolut CLI di mesin target.
Berguna bila CLI terpasang di HOME user, bukan root.
Target SSH
Autentikasi memakai kunci (BatchMode), bukan password. Pastikan kunci publik mesin ini sudah terdaftar di authorized_keys mesin target.
